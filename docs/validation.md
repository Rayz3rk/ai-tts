# 验证说明

源码发布前已完成 108 项自动测试，覆盖参数校验、预设持久化、数据检查、工作进程取消/恢复、真实训练更新与模型重载、歌声时间轴和 PostgreSQL 仓储关联。独立测试数据库启用时，全部测试通过且无跳过。

```powershell
.venv\Scripts\python.exe -m pytest -q --tb=short
```

PostgreSQL 集成测试需要设置 `AUDIO_STUDIO_TEST_DATABASE_URL`，连接独立测试集群；不要使用日常数据库。未提供测试连接时，相关测试会跳过。

还完成了实际模型生成、浏览器播放和下载一致性、批量编谱/MIDI 速度保留、390px 页面布局，以及 wheel 从源码目录外安装运行的检查。ACE-Step 使用独立 CUDA 环境完成了 30 秒原创歌曲生成；F5/RVC 完成了真实梯度更新、导出和重载。

这些检查验证软件链路和音频文件有效性，不替代主观音质评价。合成验收数据不代表个人音色训练质量。Docker 配置已进行解析检查，未声称完成容器镜像构建或 GPU 容器验收。

原 Voice-Pro 只对相关修复做了回归测试，未对其全部功能进行整体启动验收。

## 源码发布范围

发布内容包括应用源码、测试、依赖锁定文件、安装脚本、空白配置模板、使用文档及第三方许可证。

以下内容通过 `.gitignore` 留在本地：

- `.env`、数据库连接凭据、私钥和令牌文件。
- `studio_data/`、`outputs/`、`work/` 内的数据库记录、日志、录音、生成音频、模型及缓存。
- 虚拟环境、安装包、编译产物、笔记本执行结果和本机工作笔记。

详细本机验收记录不随源码发布。新安装需要按 README 自行配置数据库、下载模型，并准备自己的参考音频或训练录音。
