# 工作台使用指南

主导航按用途组织为开始创作、我的音色、作品库、训练中心、任务中心和设置。

## 开始创作

首页选择文字朗读、换音色翻唱、按旋律演唱或歌词创作新歌。每个入口说明需要准备的内容，进入后可以通过页内按钮切换创作类型；切换页面会保留当前表单内容。

- 文字朗读：输入文字并选择朗读预设，调整语速后生成。
- 换音色翻唱：上传或拖入只有人声、没有伴奏的演唱录音，选择已训练的翻唱音色。可载入本地测试干声；伴奏与转换参数按需展开。
- 按旋律演唱：歌词整段填写，配合 MIDI 或简谱。BPM 自动换算时长；逐音符编辑属于高级选项。
- 歌词创作新歌：填写歌词、风格和时长，由模型创作演唱与伴奏。

缺少组件时，页面提供准备入口；缺少翻唱音色时，引导进入我的音色。组件和音色是不同的准备事项。

## 我的音色与训练中心

朗读预设标明语言和用途，可以直接提交短句试听，或用于朗读。翻唱音色单独标注能力，流程测试模型明确标记，避免将其质量当作正式训练成果。已有转换作品时可直接回听。音色支持收藏和按收藏筛选，收藏保存在当前浏览器中。

导入翻唱音色位于我的音色；新建朗读预设从“管理朗读预设”进入。训练中心按朗读、翻唱两种用途说明数据要求，训练参数保留默认值并收进高级设置。

## 作品与任务

作品库支持原有搜索、播放、下载、改名、标签和收藏功能。任务中心集中查看全部任务，按进行中、完成、失败和取消筛选。

生成结果和创作任务详情提供“复用设置”，恢复输入内容及对应创作参数，调整后再次提交。技术日志默认折叠，任务仍支持原有取消功能。返回页面或服务重启后，可从已保存的任务读取创作设置；页面刷新后的未提交草稿暂不持久化。

## 设置

模型下载、检查点注册、运行环境、存储与数据库状态集中在设置。界面重新组织不改变原有模型、音频文件和数据库记录的存储方式。
